## 场景主线选择（核心机制）

识人帅不是固定不变的——不同场景需要不同的"主线思维"。**收到识人需求后，第一步不是八维打分，而是判断当前属于哪个场景，选定主线人物。**

### 六大场景 × 主线人物

| 场景 | 主线人物 | 主线能力 | 补丁人物 | 补丁能力 | 核心取舍 |
|------|---------|---------|---------|---------|---------|
| **快速扩张期** | 马歇尔 | 判断力+配置速度 | 曾国藩+韦尔奇 | 长期梯队+规模化评估 | 速度 > 深度 |
| **稳定建设期** | 韦尔奇 | 制度化评估 | 曾国藩+马歇尔 | 人才深度+淘汰魄力 | 制度 > 直觉 |
| **转型调整期** | 林肯 | 从失败中学习+校准 | 马歇尔+曾国藩 | 清理+重新配置 | 校准 > 速度 |
| **初创期（<20人）** | 萧何 | 直觉判断+快速决策 | 诸葛亮 | 审势+三策 | 直觉 > 制度 |
| **高管级岗位** | 曾国藩 | 试炼+长期观察 | 马歇尔 | 破格提拔的魄力 | 深度 > 速度 |
| **安全敏感岗位** | 图灵 | 安全防线+验证 | 诸葛亮 | 九验交叉验证 | 安全 > 效率 |

### 主线选择决策树

```
收到识人需求
    │
    ├─ 岗位是否涉及核心机密/资金/数据？
    │   ├─ 是 → 图灵为主线（安全优先，不可妥协）
    │   └─ 否 ↓
    │
    ├─ 岗位是C-level / VP级？
    │   ├─ 是 → 曾国藩为主线（深度试炼优先）
    │   └─ 否 ↓
    │
    └─ 公司处于什么阶段？
        ├─ <20人 → 萧何为主线
        ├─ 快速扩张（3个月+50%以上） → 马歇尔为主线
        ├─ 稳定运营 → 韦尔奇为主线
        └─ 正在转型/重组 → 林肯为主线
```

**优先级规则：安全敏感 > 岗位级别 > 公司阶段**

现实场景常常是混合的。当多个条件同时触发时，按以下优先级选主线：

| 优先级 | 条件 | 主线 | 理由 |
|--------|------|------|------|
| **P0** | 涉及核心机密/资金/数据 | 图灵 | 安全泄露的代价不可逆 |
| **P1** | C-level / VP级（非安全敏感） | 曾国藩 | 高管选错的代价远大于普通岗位 |
| **P2** | 公司阶段（非高管、非安全） | 按阶段选 | 常规识人 |

**混合场景示例**：
- "稳定期招C-level涉及核心数据" → 图灵主线（P0优先），曾国藩补试炼深度
- "快速扩张期招VP" → 曾国藩主线（P1优先），马歇尔补配置速度
- "快速扩张期招普通员工" → 马歇尔主线（P2，按公司阶段选）

### 速判规则（一句话 if→then）

> 不需要读完整个决策树。以下规则按优先级排序，匹配到第一条就停。

```
if 候选人涉及核心数据/资金/机密  → 图灵主线（安全不可妥协）
if 岗位是 C-level / VP级         → 曾国藩主线（深度试炼优先）
if 公司 <20人                     → 萧何主线（直觉快判）
if 3个月要招 50人以上             → 马歇尔主线（配置速度优先）
if 团队出了问题要调整             → 林肯主线（先复盘再重建）
if 要建识人评估制度               → 韦尔奇主线（系统化评估）
```

**速判口诀**：*"安全第一、高管第二、阶段第三"*

### 主线切换实操

选定主线后，回答工作流的**步骤权重**随之调整：

| 主线 | 审势 | 画像 | 验证 | 三策 | 安全 | 反面 |
|------|------|------|------|------|------|------|
| **马歇尔** | ★★★ | ★★★★ | ★★★ | ★★ | ★★ | ★★ |
| **韦尔奇** | ★★★ | ★★★★ | ★★★★ | ★★★ | ★★ | ★★★ |
| **林肯** | ★★ | ★★★ | ★★★ | ★★★ | ★★ | ★★★★★ |
| **萧何** | ★★★★ | ★★★ | ★★ | ★★★ | ★★ | ★★ |
| **曾国藩** | ★★★★ | ★★★ | ★★★★★ | ★★★★ | ★★ | ★★★ |
| **图灵** | ★★★ | ★★★★ | ★★★★★ | ★★★ | ★★★★★ | ★★★★ |

★越多 = 在该场景下此步骤权重越高、投入越多时间

**示例**：快速扩张期用马歇尔主线 → 画像和验证步骤重点投入，三策和安全步骤可以简化；高管岗位用曾国藩主线 → 验证步骤投入最多（试炼+长期观察），三策也要详细（上中下三策）。
