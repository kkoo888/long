### 附录 B：九维失效条件速查表

| 维度 | 核心失效条件 | 对策 |
|------|------------|------|
| 判断力 | 全新行业、信息不足、候选人伪装、跨文化 | 增加验证维度、降低置信度标注 |
| 直觉力 | 近因效应、光环效应、相似性偏误、疲劳 | 反面证据 + 事后校准 + 休息 |
| 配置力 | 快速变化期、新设岗位、信息不对称 | 缩短评估周期、增加试用期 |
| 验证力 | 候选人知悉流程、时间紧迫、背调来源被污染 | 多维度验证、独立寻找背调来源 |
| 制度力 | 僵化走形式、过度制度化、更新滞后、被高层绕过 | 定期审视制度有效性 |
| 公心 | 自身私心不自知、组织文化鼓励用自己人 | 外部校准者、制度化制衡 |
| 抗压力 | 判断无据变成固执、长期对抗被边缘化 | 区分坚持正确 vs 坚持面子 |
| 安全力 | 内部人员是攻击者、远程办公边界模糊 | 分级管理、安全文化建设 |
| 识人攻防 | 过度怀疑错失人才、攻防策略被知悉、文化差异误判 | 攻防是验证手段不是默认立场、保持策略隐蔽性 |

### 附录 C2：直觉记录与校准模板

```markdown
## 直觉记录卡
## 日期：[YYYY-MM-DD]

## 场景：[面试/会议/背调/非正式交流]

- 触发因素：[什么细节触发了这个感受？具体行为/言语/非语言信号]

- 此人像谁：[你见过的哪个人与此人相似？相似点在哪？]
- 此人不像谁：[与哪类人明显不同？不同点在哪？]
- 历史案例：[类似类型的人，过去结果如何？]

### 偏误自检（达尔文四问）
1. 近因效应？→ 最近见的几个人是否影响了判断？[是/否]
2. 光环效应？→ 是否被某个突出优点遮盖了缺点？[是/否]
3. 相似性偏误？→ 是否因为"像自己"而加分？[是/否]
4. 疲劳效应？→ 是否连续面试了3人以上？[是/否]

### 反面证据（必填）
- 支持直觉的证据：[1-2条]
- 反对直觉的证据：[1-2条] ← 这条最重要

### 校准记录（6个月后回填）
- 最终结果：[此人实际表现如何？]
- 直觉准确度：[对/错/部分对]
- 复盘：[当时有没有"感觉不对但忽略了的瞬间"？]
```

### 附录 D：安全规范速查

| 场景 | 安全要求 |
|------|---------|
| 评估报告传输 | 加密传输，阅后即焚或限时访问 |
| 背调结果讨论 | 仅限决策层，不在群聊/开放场合讨论 |
| 人才档案存储 | 加密存储，权限最小化，定期审计访问日志 |
| 面试评价互通 | 面试官之间不互通评价，防止从众效应 |
| 候选人信息外泄 | 签署保密协议，识人团队成员设备安全检查 |
| 社工攻击防范 | 背调联系人双重来源（候选人提供+独立寻找） |
