## 识人系统季度校准（八阵图·闭环机制）

> "八阵图之所以厉害，不是阵型本身，是它能根据敌军变化自动调整。"——一个不会进化的系统，终究会僵化。

### 季度校准流程（Session C 改制）

每季度末，花2-3小时做一次识人系统校准：

```
Step 1: 回顾（30分钟）
├─ 本季度做了多少次识人判断？
├─ 其中多少次进入了完整九验流程？
├─ 多少次用了速查/MVTS方案？
└─ 记录到校准表

Step 2: 统计（30分钟）
├─ 6个月前的判断，现在可以回填结果了
├─ 统计准确率：判断"录用"的人，实际表现如何？
├─ 统计失误率：判断"不录用"的人，去了竞品表现如何？
└─ 计算总体准确率（目标：>70%）

Step 3: 归因（30分钟）
├─ 出错的判断，是因为哪个维度失效？
│   ├─ 判断力失效？（看错了德/才/志/性）
│   ├─ 直觉力失效？（被偏误干扰）
│   ├─ 验证力失效？（九验没做够/做假了）
│   ├─ 配置力失效？（人岗不匹配）
│   └─ 安全力失效？（信息泄露/被欺骗）
├─ 哪类岗位最容易出错？（高管？技术？销售？）
└─ 哪个主线人物的方法论准确率最高？

Step 4: 修正（30分钟）
├─ 根据数据调整判断规则
│   例：连续3次"大厂VP转创业"判断失误
│   → 降低此类判断的置信度，增加"验之以事"权重
├─ 更新速查规则中的优先级
└─ 将修正写入本SKILL.md

Step 5: 归档（30分钟）
├─ 更新人才档案（已入职的人跟踪表现）
├─ 更新反面证据库（新的失败案例）
└─ 写入校准日志：memory/YYYY-MM-DD-calibration.md
```

### 校准触发条件（不只靠季度）

除了定期校准，以下情况也需要立即触发校准：
- **重大失误**：招进来的人3个月内离职或被辞退 → 立即复盘
- **模式发现**：连续2次同类判断出错 → 立即修正规则
- **环境变化**：公司阶段发生重大变化（融资、裁员、转型）→ 重新评估主线选择的有效性
