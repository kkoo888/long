## 一、方案总纲

### 糅合三原则

1. **不要拼接，要糅合**——先定骨架再填肉，先解决矛盾再写入
2. **不要平等混合，要有主线**——一人做骨架，其他人做补丁
3. **直接糅合有章法**——有取舍、有主次、有矛盾折中

### 核心升级（v3.0 vs v2.1 vs v1.0）

| 维度 | v1.0 | v2.1 | v3.0 |
|------|------|------|------|
| 能力模型 | 8维平铺 | 8维分层+优先级 | **9维**（新增攻防层）+ 优先级 |
| 主线选择 | 缺失 | 六大场景×主线人物 | 六大场景 + **速判规则（if→then）** |

## 三、场景主线选择（核心机制）

### 六大场景 × 主线人物

| 场景 | 主线人物 | 主线能力 | 补丁人物 | 补丁能力 | 核心取舍 |
|------|---------|---------|---------|---------|---------|
| **快速扩张期** | 马歇尔 | 判断力+配置速度 | 曾国藩+韦尔奇 | 长期梯队+规模化评估 | 速度 > 深度 |
| **稳定建设期** | 韦尔奇 | 制度化评估 | 曾国藩+马歇尔 | 人才深度+淘汰魄力 | 制度 > 直觉 |
| **转型调整期** | 林肯 | 从失败中学习+校准 | 马歇尔+曾国藩 | 清理+重新配置 | 校准 > 速度 |
| **初创期（<20人）** | 萧何 | 直觉判断+快速决策 | 诸葛亮 | 审势+三策 | 直觉 > 制度 |
| **高管级岗位** | 曾国藩 | 试炼+长期观察 | 马歇尔 | 破格提拔的魄力 | 深度 > 速度 |
| **安全敏感岗位** | 图灵 | 安全防线+验证 | 诸葛亮 | 九验交叉验证 | 安全 > 效率 |

### 主线选择决策树

```
收到识人需求
    │
    ├─ 岗位是否涉及核心机密/资金/数据？
    │   ├─ 是 → 图灵为主线（P0，安全优先不可妥协）
    │   └─ 否 ↓
    │
    ├─ 岗位是C-level / VP级？
    │   ├─ 是 → 曾国藩为主线（P1，深度试炼优先）
    │   └─ 否 ↓
    │
    └─ 公司处于什么阶段？（P2）
        ├─ <20人 → 萧何为主线
        ├─ 快速扩张 → 马歇尔为主线
        ├─ 稳定运营 → 韦尔奇为主线
        └─ 正在转型 → 林肯为主线
```

**优先级：安全敏感 > 岗位级别 > 公司阶段**

混合场景示例：
- "稳定期招C-level涉及核心数据" → 图灵主线（P0），曾国藩补试炼
- "快速扩张期招VP" → 曾国藩主线（P1），马歇尔补速度
- "快速扩张期招普通员工" → 马歇尔主线（P2）

### 速判规则（v3.0 新增）

> 不需要读完整个决策树。以下规则按优先级排序，匹配到第一条就停。

```
if 候选人涉及核心数据/资金/机密  → 图灵主线（安全不可妥协）
if 岗位是 C-level / VP级         → 曾国藩主线（深度试炼优先）
if 公司 <20人                     → 萧何主线（直觉快判）
if 3个月要招 50人以上             → 马歇尔主线（配置速度优先）
if 团队出了问题要调整             → 林肯主线（先复盘再重建）
if 要建识人评估制度               → 韦尔奇主线（系统化评估）
```

**速判口诀**：*"安全第一、高管第二、阶段第三"*

## 四、内在张力与折中方案

### 张力一：直觉力 vs 验证力

| 极端 | 风险 | 折中 |
|------|------|------|
| 纯直觉（萧何） | 被表象欺骗 | 直觉为矛，验证为盾 |
| 纯验证（韦尔奇） | 错过潜力股 | 直觉筛选，验证确认 |

### 张力二：安全力 vs 效率

| 极端 | 风险 | 折中 |
|------|------|------|
| 极致安全 | 流程拖沓 | 分级管理 |
| 极致效率 | 信息泄露 | 一般岗位保效率，关键岗位保安全 |

### 张力三：判断力 vs 制度力

| 极端 | 风险 | 折中 |
|------|------|------|
| 纯个人判断 | 不可持续 | 制度为底，判断为顶 |
| 纯制度流程 | 漏掉天才 | 日常走制度，关键保留判断权 |

### 张力四：公心 vs 抗压力

| 极端 | 风险 | 折中 |
|------|------|------|
| 纯公心 | 忽视政治现实 | 公心是底线，抗压是工具 |
| 纯抗压 | 固执己见 | 区分坚持正确 vs 坚持面子 |

### 张力五：直觉力 vs 制度力

| 场景 | 折中 |
|------|------|
| 直觉说"不对"，制度说"通过" | 用验证力再做一轮深度检查 |
| 直觉说"很好"，制度说"不通过" | 先尊重制度结论，记录直觉，半年后回看 |
| 直觉和制度一致 | 直接决策，置信度最高 |

**核心原则**：制度是底线（不可跳过），直觉是上限（可以加分但不能减分）。

## 七、执行路线图

### Phase 1：审势选主线（第1天）

1. 判断当前属于哪个场景
2. 选定主线人物
3. 确定补丁人物
4. 明确工作流步骤权重

### Phase 2：识人评估（第1-2周）

1. 按主线权重执行工作流各步骤
2. 完成至少五验
3. 记录直觉判断
4. 收集反面证据

### Phase 3：决策输出（第2周末）

1. 给出三策
2. 安全提醒
3. 反面审视
4. 记录在人才档案

### Phase 4：校准回看（持续）

1. 每次判断后记录
2. 半年后回看准确率
3. 更新判断模型
4. 每季度九维自评

### Phase 5：季度系统校准（v3.0 新增）

1. 回顾本季度识人判断次数和类型
2. 统计6个月前判断的准确率
3. 归因分析：哪类岗位最容易出错？哪个维度最容易失效？
4. 修正判断规则，更新SKILL.md
5. 归档人才档案和反面证据库

**触发条件**：定期（每季度）+ 事件驱动（重大失误/模式发现/环境变化）

## 资源受限速查（v3.0 新增）

> 创业公司识人，往往资源不足。以下是最低可行识人方案（MVTS）。

| 你的情况 | 最低方案 | 置信度 | 后续补强 |
|---------|---------|--------|---------|
| 只有1天 | 事+言+旧 | 中 | 入职后1个月补众+败 |
| 只有1小时 | 言+败 | 低 | 必须设3个月试用期 |
| 没有HR | 创始人做事+旧，朋友做众 | 中 | 招到第一个HR后补完整流程 |
| 预算为0 | LinkedIn背调+行业社群口碑+公开项目审查 | 低 | 转正前必须完成旧 |
| 紧急<1周 | 旧+言 + 必须试用期 | 低 | 降低三策期望 |

**三原则**：事+旧不可省 | 时间越短试用期越长 | 信息不足时保守三策优先

## 九、反面教材：从历史失误中学习

> "前事不忘，后事之师。"——每个反面教材都对应本方案的一个能力缺陷。

| 人物 | 识人失误 | 对应能力缺陷 | 如果用本方案如何避免 |
|------|---------|-------------|-------------------|
| 蒋介石 | 识人有术但用人有私 | **公心** | 公心自检"关系检验"+校准会议暴露"用听话的人"模式 |
