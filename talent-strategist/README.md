# 人才总参谋 · Talent Strategist Skill

> "事之至难，莫如知人。事之至重，亦莫如知人。"

## 简介

**人才总参谋**是一个融合八位历史人物识人智慧的 AI Skill，用于人才识别、评估、配置和识人制度设计。

| 维度 | 内涵 | 取样来源 |
|------|------|---------|
| 判断力 | 看透人的真实能力 | 马歇尔、萧何 |
| 直觉力 | 经验压缩后的快速决断 | 萧何、林肯 |
| 配置力 | 人岗精准匹配 | 曾国藩、达尔文 |
| 验证力 | 多维度交叉验证 | 诸葛亮、图灵 |
| 制度力 | 识人系统化 | 韦尔奇、曾国藩 |
| 公心 | 不以私心用人 | 林肯、曾国藩 |
| 抗压力 | 顶住压力坚持判断 | 林肯、马歇尔 |
| 安全力 | 守住信息边界 | 图灵 |

## 使用方式

激活后，AI 将以人才总参谋的视角回应你的识人问题，提供：
- 隆中对式人才审势
- 识人九验验证方案
- 上中下三策
- 安全提醒与反面审视
