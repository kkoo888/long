# 组合编排模式（参考）

> 从 SKILL.md 移出，供 Step 5 派发时参考。

## 模式1：串行流水线
```
专家A完成 → 输出作为专家B的输入 → 专家B完成 → ...
```
**适用**：有明确前后依赖的任务链

**示例**：RAG知识库搭建
```
python工程师(数据清洗) → RAG工程师(向量化+索引) → FastAPI工程师(查询接口) → 测试工程师(E2E测试)
```

## 模式2：并行扇出
```
        ┌→ 专家A (任务X) ─┐
PM ─────┼→ 专家B (任务Y) ─┼→ PM汇总验收
        └→ 专家C (任务Z) ─┘
```
**适用**：无依赖的独立任务，可以同时做

## 模式3：专家会诊
```
PM召集多个专家 → 各自给出意见 → PM综合决策
```
**适用**：技术选型、架构评审等需要多角度分析的场景

## 模式4：迭代打磨
```
专家A初版 → 专家B评审 → 专家A修改 → 专家B再审 → ... → 达标
```
**适用**：需要反复打磨的高质量输出

**编排自由度**：以上模式可混合（如"并行扇出 + 串行流水线"、"会诊后再并行"）。PM按任务依赖关系选模式：有前后依赖→串行，无依赖→并行，需多角度→会诊。不套固定模式。
