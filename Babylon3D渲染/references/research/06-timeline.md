## Babylon.js 诞生与发展

### 2013年 - 项目创立

- **Babylon.js 作为 side project 诞生**：David Catuhe 与 David Rousset（@davrous）在微软内部孵化 Babylon.js，最初作为 TypeScript 项目启动。目标是提供一个易于使用、功能强大的 WebGL 框架。
  - 来源：[Microsoft Open Source Blog - Babylon Success Story (2021)](https://opensource.microsoft.com/blog/2021/02/22/microsoft-open-source-success-story-babylon/)（"Babylon was 'born open' as a side project of Microsoft engineer David Catuhe"）
  - 来源：[知乎 - WebGL开发:BabylonJS从入门到精通](https://zhuanlan.zhihu.com/p/1890787692993828290)（"2013年: BabylonJS 由 David Catuhe 和 David Rousset 在微软内部孵化"）

- **共同创始人**：Babylon.js 由 David Catuhe (@deltakosh)、David Rousset (@davrous)、Pierre Lagarde (@pierlag) 和 Michel Rousseau (@rousseau_michel) 共同创建。
  - 来源：[CSDN - Babylon.js 精要](https://blog.csdn.net/wizardforcel/article/details/152046225)

- **2013年10月28日**：首次公开发布，通过 MSDN 博客文章 "Babylon.js - The Train Demo" 发布。
  - 来源：[CSDN - 测试WebGL的极限](https://blog.csdn.net/dingshi7798/article/details/105824934)（引用原始链接：http://blogs.msdn.com/b/eternalcoding/archive/2013/10/28/babylon-js-the-train-demo.aspx）

- Babylon.js 持续迭代，以 MIT 协议开源。
- 2013年 Turbulenz 引擎也基于 MIT 协议开源，两者同期竞争。

### 2015年 - 关键转折点

- **"3D for everyone" 项目**：通过开源协作模式，Babylon.js 展示了令人惊叹的渲染能力，引起了微软产品领导者的注意。
  - 来源：[Microsoft Open Source Blog](https://opensource.microsoft.com/blog/2021/02/22/microsoft-open-source-success-story-babylon/)（"in 2015 through the Open Source collaborative model was able to demonstrate incredible rendering capabilities in a project called '3D for everyone'—catching the eye of product leaders very early on"）

- **从 side project 到全职工作**：David 的副业项目变成了他的全职工作，团队的主要焦点。
  - 来源：同上（"David's side-project became his full-time job, and his team's primary focus"）

### 2016年 - 2.x 版本期

### 2021-2022年 - 5.x 版本期

- **2021年2月**：微软开源博客发表 Babylon.js 成功故事文章，称其为微软开源的典范。

- **2022年5月**：Babylon.js 5.0 正式发布，带来出色的 WebXR 渲染性能、光线估计功能、GUI 编辑器测试版。

### 2023年 - 6.x 版本期

- **2023年4月**：Babylon.js 6.0 发布，最大亮点是引入 Havok 物理引擎（通过 WASM 插件），性能提升20倍。新增性能优先模式（Performance Priority Modes），渲染性能提升高达50倍。
  - 来源：[IT之家 - 微软发布Babylon.js 6.0](https://www.ithome.com/0/687/954.htm)
  - 来源：[腾讯云开发者社区](https://cloud.tencent.cn/developer/news/1058263)

### 2024年 - 7.x 版本期

- **2024年3月28日**：Babylon.js 7.0 发布，主要新特性包括：
  - Node Geometry（几何节点）：非破坏性节点树系统创建程序化几何
  - 全局光照（Global Illumination）
  - Apple Vision Pro 支持
  - WebXR 优化
  - 来源：[IT之家 - 微软发布Babylon.js 7.0](https://www.ithome.com/0/758/864.htm)
  - 来源：[映维网 - Babylon.js 7.0 WebXR优化](https://xueqiu.com/6417412234/284496896)

### 2025-2026年 - 8.x 版本期（当前）

- **2025年3-4月**：Babylon.js 8.0 发布，主要新特性包括：
  - WebGPU 原生支持，核心着色器全面迁移至 GLSL/WGSL，移除转换层，运行效率翻倍
  - IBL Shadow（基于图像照明的阴影）
  - WebXR Depth Sensing（深度感知功能）
  - USDZ 导出支持
  - 来源：[搜狐 - Babylon.js 8.0发布](https://www.sohu.com/a/876844870_122004016)
  - 来源：[映维网 - Babylon.js 8.0 WebXR Depth Sensing](https://news.nweon.com/128882?login=0)

- **2025-2026年持续活跃**：GitHub 仓库持续高频提交（2026年5-6月仍有每日多次提交），25k+ stars，3.7k forks。
  - 来源：[GitHub - BabylonJS/Babylon.js](https://github.com/BabylonJS/Babylon.js/)

## 总结：从 Side Project 到微软战略资产

David Catuhe 的故事是一个经典的"工程师副业改变命运"叙事：

1. **2013年**：作为微软 Edge/Web 标准团队的 PM，出于对3D图形的热爱，与同事 David Rousset 启动了 Babylon.js 这个 side project
2. **2015年**：通过开源协作模式展示的"3D for everyone"愿景，吸引了微软产品领导层的关注
3. **Side project → 全职**：Babylon.js 从副业变成了 David 的全职工作和团队核心焦点
4. **产品整合**：Babylon.js 逐步被整合进微软核心产品（Teams、PowerPoint、SharePoint、OneDrive）
5. **战略地位提升**：David 从 PM 转型为 Engineering Lead，再到 Partner Group Engineering Manager，领导数百人团队
6. **行业影响**：Babylon.js 成为与 Three.js 并列的 Web 3D 引擎双雄之一，25k+ GitHub stars
